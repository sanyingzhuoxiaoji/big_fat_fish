# 大肥鱼桌宠实施计划

> 执行方式：分模块实现，逐阶段验证，连续推进。阶段结果记录在 `docs/PROGRESS.md`，不可把静态检查或模拟接口当作实际运行验收。

## 已确认目标

独立 Windows Electron 桌宠，使用当前目录 Live2D 大肥鱼模型；支持 GLM API 流式聊天，通过真实工具读写 desktop_note；保留便签独立运行、双向同步；番茄钟关联待办；指定时间由便签统一调度提醒，桌宠显示气泡与动作。

## 权限与数据边界

- 应用实现仅在本项目；关联便签修改限定为确认身份后的 `D:/project/便签`（desktop_note）。参考 Angelina_Pet 和鲸语不直接修改。
- 不修改系统、代理、OMP配置，不操作无关文件。
- 不改变模型文件；从现有目录加载，补充的动作/表情索引在应用内生成。
- API Key 不进入源码、文档、日志或 Git；只在应用主进程内存使用，用户明确选择保存时才通过 Electron safeStorage 加密。
- 本项目运行数据放 `.local/`。验证使用项目内隔离便签数据目录，不改用户真实待办。
- 待办唯一管理者是 desktop_note 主进程。便签界面和桌宠通过任务命令修改状态，禁止两个应用同时写同一个JSON。
- GitHub：有阶段性已验证成果后提交/推送；排除模型、密钥、会话、运行数据。若无仓库或登录权限，记录阻塞，继续本地开发。

## 技术决策

Electron + 原生 HTML/CSS/JS，不引入前端框架。模型使用官方 Cubism Core、PIXI及pixi-live2d-display；参考鲸语同模型驱动方式。业务和网络请求位于主进程，渲染端通过限定IPC访问。

GLM依据官方文档 https://docs.bigmodel.cn/cn/guide/models/free/glm-4.7-flash ，默认通用端点 `https://open.bigmodel.cn/api/paas/v4/chat/completions`、`glm-4.7-flash`，模型与地址可配置。使用原生fetch、SSE流与function calling，模型不能直接执行系统命令。

## 文件与职责

- `src/main.cjs`、`src/preload.cjs`：窗口、托盘、受限IPC与启动生命周期。
- `src/ui/`：透明模型窗口、聊天/任务/专注/设置面板、Live2D适配。
- `src/app-service.cjs`：应用状态与IPC业务编排。
- `src/services/note-client.cjs`：便签发现、HTTP命令、SSE同步。
- `src/services/chat.cjs`：GLM流式聊天、会话与工具调用循环。
- `src/services/pomodoro.cjs`：可恢复的计时状态、任务关联、专注记录。
- `scripts/`：本地资源准备与验收入口。
- `tests/`：会导致用户可见问题的业务回归测试。
- 便签关联目录：主进程权威任务存储、本机桥接服务、renderer/preload命令调用适配。

## 阶段与验收

### 1. 模型加载与桌宠窗口
- [ ] 资源准备、透明置顶窗口、拖动、穿透与托盘恢复。
- [ ] 模型实际渲染；待机、表情与动作正常；缺失资源显示真实错误。
- [ ] 打开真实Electron窗口检查并保存截图/运行证据。

### 2. desktop_note 双向接口
- [ ] 确认本地便签仓库身份；保留现有图片、状态、备注、提醒及外观字段。
- [ ] 主进程统一任务状态；便签UI与外部客户端共用任务命令，不再用旧快照覆盖新任务。
- [ ] 本机鉴权接口、连接快照、状态变更及提醒事件、重连对账。
- [ ] 隔离数据下验证两边交替增改完成、旧界面不覆盖外部新增、重连状态一致。

### 3. GLM聊天与任务工具
- [ ] 设置API地址/模型/Key，流式对话、本地会话记录、清除会话。
- [ ] 查询/新增/修改/完成待办，以及启动番茄钟工具。
- [ ] 保存成功才能声称完成；含糊提醒时间应澄清；不向模型发送图片或无关数据。
- [ ] 使用用户提供的临时Key真实验证普通聊天及任务工具；真实失败如实记录。

### 4. 番茄钟与提醒
- [ ] 选择任务、工作/休息、暂停/继续/结束、持久化恢复。
- [ ] 时间基准计算剩余时长；关闭面板不中断；重启和休眠采用可解释规则。
- [ ] 便签负责唯一待办提醒调度；桌宠接收事件并展示；番茄结束不自动完成任务。
- [ ] 实测短计时及到点提醒；验证重启恢复和同一待办不重复触发。

### 5. 完整流程验收
- [ ] 真GLM聊天创建任务→便签UI可见→桌宠绑定专注→到点提醒→完成并双向同步。
- [ ] 实际UI验证设置、状态反馈及失败提示。
- [ ] 提供本地启动入口、使用说明、许可说明、阶段记录和准确的剩余问题。
- [ ] 有进展后推送GitHub；记录仓库URL和已推送提交。

## 用户可见规则

- 时间回显为明确日期及当地时间；提醒时间不是截止日期。
- 完成一轮番茄钟不自动完成任务。
- 系统关机期间无法即时通知；便签启动后补发过期提醒。
- API不可用不影响本地计时和已安排提醒。
- 模型不得擅自再分发；Git排除模型包，公开内容保留原画神宫凉子、建模霓虹猫_NeonNeko署名。Cubism Core按官方许可使用。
